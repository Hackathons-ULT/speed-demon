# C: Join

On Linux, a read-only file mapping exposes the input through the existing page cache. Six workers parse disjoint logical-record ranges. A quote-parity prepass finds safe cuts: every quote toggles parity, including both bytes of an escaped pair, and an LF at even parity is a record terminator. The AVX2 implementation computes prefix parity over 32-byte blocks; a scalar fallback gives identical cuts. This handles quotes straddling blocks, embedded newlines, BOMs, CRLF and LF terminators, long fields spanning multiple partition targets, and an unterminated final record. Workers search quoted spans with `memchr` and count decoded bytes without constructing name or note strings. Windows uses a private read buffer for development checks.

The lookup is a dense vector of 16-bit country IDs, sized from the actual region table. A direct 26-by-26-by-26 table maps the specified three-uppercase-letter country codes while loading it. All 17,576 possible codes fit in 16 bits; holes and IDs above the region vector map to `_UNMATCHED`. Each worker owns its numeric aggregates. Counters and money values use 64-bit integers; money is parsed in exact cents, including negative sub-unit amounts, then formatted with two fractional digits.

A shared open-addressed name table interns payload views into the mapped input. Each sixteen-byte slot contains an atomic hash tag, a byte length and an immutable payload pointer. Hashes only filter candidates: equality always compares the complete payload. A worker atomically reserves an empty slot, fills the payload, then publishes its tag with release semantics. Readers wait for reservations and acquire the published tag before reading the payload. The slot index supplies its name ID, avoiding a separate allocation and global ID increment on the common path.

Each lookup examines at most 32 slots. A full probe window or an overlength payload falls back to an exact chained interner with IDs starting above the inline table's capacity. Its buckets are allocated only when required; it has no fixed distinct-name limit. Slots never move or become empty. Therefore a value inserted inline cannot later fall through to the chain, and a value routed to the chain cannot later find a newly empty inline slot. Waiting for reserved slots prevents concurrent occurrences from splitting between the two stores. Chained nodes retain stable per-worker arenas and release/acquire publication. Table capacity is a performance choice, not an assumed name pool or a correctness limit.

Each country has a growable linked bitmap of global name IDs. Blocks are initialized once and published atomically; each worker caches its block pointers privately. An atomic bit operation identifies exactly one first occurrence of a `(country, name)` pair, and that winner increments its private distinct counter. Summing private counters is therefore an exact union, without merging large per-worker sets. Joining every worker before summing and sorting country output removes scheduling from the result. IDs may be assigned in a different order, but no ID is printed and all observable aggregates are invariant.

This avoids decoding and copying name strings while preserving exact equality. Strip only the outer CSV delimiters: every literal quote in the value must be doubled in the remaining payload. That encoding is injective, so two payloads are equal exactly when their decoded values are equal. An unquoted field cannot contain a quote, and its payload is the same as a quoted representation of that value. In particular, quoted and unquoted empty names both have an empty payload; trailing-space twins remain distinct. Decoded byte lengths are counted separately, with each doubled quote contributing one byte. This representation changes storage, not the specified equality or length semantics.

Country output is sorted and zero-count entries are omitted. Auxiliary memory depends on the maximum known region ID, global distinct names, and country/name bitmap capacity; it does not replicate whole dictionaries per worker. The input mapping is read-only and no input-derived state survives the process. Numeric parsing, boundary scanning and all lookups are inside the timed run. C++ standard library, standard threading and POSIX mapping APIs add no runtime package dependency. Build with `-pthread`. The default is six workers; `C_WORKERS` supports one to twelve for controlled development measurements.

With another 24 hours, profile atomic membership cache traffic and tune the inline capacity, probe window and worker count against measured source/memory/time costs. Keep parser fixtures, partition-boundary tests and multi-worker differential tests as correctness gates.
