# C: Join

On Linux, a read-only file mapping exposes the input through the existing page cache. A pointer parser consumes logical CSV records. It searches quoted spans with `memchr`, unescapes name quotes, and counts decoded note bytes without constructing a note string. Embedded LF, commas, trailing spaces and UTF-8 bytes remain exact. BOM bytes are skipped only at a logical record boundary, so a BOM within a quoted value remains data. CRLF and LF terminators and an unterminated final record are supported. Windows uses a private read buffer for development checks.

The lookup is a dense vector of country IDs, sized from the actual region table. Holes and IDs above that vector map to `_UNMATCHED`. Each record accesses its country aggregate directly instead of searching a country tree. Counters and money values use 64-bit integers. Money is parsed in exact cents, including negative sub-unit amounts, then formatted with two fractional digits. A global hash map interns each exact unescaped name once; each country keeps a growable bitmap of those IDs and a distinct-name counter. Quoted and unquoted empty names compare equal, while trailing-space twins remain distinct. Byte lengths are measured after quote unescaping.

Country output is sorted and zero-count entries are omitted. Auxiliary memory depends on the maximum known region ID, global distinct names, and country/name bitmap capacity; the input mapping is read-only and no input-derived state survives the process. Numeric parsing, record scanning and all lookups are inside the timed run. The C++ standard library and POSIX mapping APIs add no direct runtime package dependency.
